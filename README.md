# 🚀 Inside the Algorithm

> **Watch Machine Learning Happen — No Code, No Setup.**

Inside the Algorithm is an interactive Machine Learning visualization platform designed to make complex ML concepts easy to understand through engaging animations and interactive experiences.

This repository currently contains the **Landing Page (Page 1)** of the project, built using **React** and **Vite**.

---

# 🚀 Getting Started

## 1. Clone the Repository

```bash
git clone https://github.com/your-username/inside-the-algorithm.git
```

## 2. Navigate to the Project

```bash
cd inside-the-algorithm
```

## 3. Install Dependencies

```bash
npm install
```

## 4. Start the Development Server

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```
